# D Shiva Prasad Portfolio

A responsive React + TypeScript portfolio website for D Shiva Prasad, Software Engineer / React Native Developer.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production output is generated in `dist/` and can be deployed to Vercel, Netlify, GitHub Pages, or any static hosting service.

## Customize

- Update project data in `src/main.tsx`.
- Update styling in `src/styles.css`.
- Add your resume PDF to `public/` and change the Download Resume button if desired.

## Resume
The portfolio includes the source resume PDF at `public/D-Shiva-Prasad-Resume.pdf`. The header and contact section link to it.
